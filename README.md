# 藥聲 YaoSheng

給在台灣照顧家人的外籍看護用的藥袋語音助手。拍照或選一張藥袋，整理藥袋上依法應記載的欄位，並用照顧者的語言顯示、朗讀。家屬頁一律是繁體中文。

藥聲**只翻譯並朗讀藥袋上的文字與提醒**。它不判斷劑量對不對，不建議停藥，也不另外寫醫療建議。兩張藥袋出現同一成分時，只標「請詢問藥師」。

介面語言：Bahasa Indonesia、Tiếng Việt、Filipino、ภาษาไทย、中文。

## 一個指令啟動

```bash
npm install
npm run dev
```

安裝完成後，之後每次只要：

```bash
npm run dev
```

瀏覽器打開 [http://127.0.0.1:4321](http://127.0.0.1:4321)。手機與電腦都可以。沒有 API 金鑰也能走完所有畫面。

其他指令：

```bash
npm test          # 重複藥與今日時間軸
npm run lint
npm run build && npm start   # 正式模式，會註冊簡易 PWA
npm run build:static         # 純靜態展示包，產出 out/
```

## 手機上的靜態展示（離線示範，不是正式版）

`npm run build:static` 會做出不含後端的網站，放在 `out/`。這包**不能拍照辨識**，畫面上會寫「展示版未開啟拍照辨識」。它只適合沒有伺服器時看畫面。正式使用請部署 Next.js / Cloudflare Workers。

把這個資料夾放到任何靜態檔案伺服器的根目錄即可，手機瀏覽器直接開首頁。

```bash
npm run build:static
cd out && python3 -m http.server 8765
```

這包是離線展示，不是正式版。點拍照或從相簿選圖時，不會呼叫辨識介面，畫面上會寫「展示版未開啟拍照辨識」。可以手動輸入，或在這個展示包裡打開標示清楚的示範藥袋。藥卡網址用查詢參數（`/meds/card/?id=...`），重新整理也不需要伺服器把所有路徑轉回同一頁。

## 哪些功能需要 OPENAI_API_KEY

沒有金鑰也能日常使用：手動輸入藥袋、今天的給藥時間、已餵藥／漏吃紀錄、提醒（畫面開著時）、重複成分提示、匯出與匯入備份。

需要金鑰的只有兩件事：

- **拍照辨識**（`/api/extract`）：讀取藥袋上的文字。
- **自動翻譯**（辨識結果，或手動輸入後的 `/api/translate`）：譯成照顧者的語言（印尼語、越南語、菲律賓語、泰語、英語）。

金鑰留在 Cloudflare Worker 的 Secret，不要寫進 git。沒有金鑰時，辨識會回 503，畫面會請你改手動輸入。

## 試用示範資料（要自己打開）

新安裝是空的。設定裡的「試用示範資料」才會載入四張虛構藥袋，患者都是**林秀英**（非真實處方）。畫面上會標「示範」，而且**不會**和真實藥袋放在一起。要改回真實使用，按「清除示範資料」。

| 藥袋 | 藥品 | 藥袋上的用法 |
| --- | --- | --- |
| 國泰綜合醫院 | 脈優錠 5 毫克（Amlodipine，降血壓） | 早餐後，每日一次 |
| 臺北市立聯合醫院仁愛院區 | 格華止膜衣錠 500 毫克（Metformin，降血糖） | 早餐後與晚餐後 |
| 亞東紀念醫院 | 艾必克膜衣錠 5 毫克（Apixaban，抗凝血） | 早上與晚上各一次 |
| 大安健康藥局 | 安脈優錠 5 毫克（Amlodipine，降血壓） | 早餐後，每日一次 |

最後一包與國泰那包成分相同。藥櫃與今天的時間軸會標「請詢問藥師」，**不會**告訴你該停哪一種。

用法、警語的譯文是事先寫好的固定句子，不是臨時生成的。時間圖示（飯前、飯後、睡前、早中晚）也只對應藥袋上寫的字。

資料存在這支瀏覽器的 localStorage。沒有帳號、沒有後端資料庫。

## 開啟拍照辨識（選用）

1. 複製環境變數檔：`cp .env.example .env.local`
2. 在 `.env.local` 填入 `OPENAI_API_KEY`
3. 可改 `OPENAI_MODEL`（預設 `gpt-4o-mini`）與 `OPENAI_BASE_URL`（相容 OpenAI Chat Completions 的服務）
4. 停掉再執行 `npm run dev`

拍照或從相簿選圖時，圖片會送到該模型，**只**讀取並翻譯藥袋上看得到的欄位。看不見的欄位留空，畫面上會寫「藥袋上未見此欄」。讀完後請對著藥袋核對，再收入藥櫃。金鑰只留在伺服器，不會寫進瀏覽器。

沒有金鑰就上傳照片時，伺服器回 503，畫面會請你改手動輸入。它不會假裝已經讀到藥袋。手動輸入後若要自動翻譯，同樣需要這把金鑰。

提醒只在藥聲開著時會響。iPhone 鎖定或關掉瀏覽器之後不會在背景響鈴。已餵藥與漏吃存在這支手機，設定裡可以匯出或匯入 JSON 備份，也可以清除全部資料。

## 部署到 Cloudflare Workers

專案用 OpenNext 跑在名為 `sounds-of-medicine` 的 Worker 上。`wrangler.jsonc` 的 `name` 與 `WORKER_SELF_REFERENCE` 都是這個名稱。

Workers Builds 請分開設定：

- 建置指令：`npx opennextjs-cloudflare build`（會先跑 `npm run build`，再產出 `.open-next/`）
- 部署指令：`npx wrangler deploy`

本機：

```bash
npm run preview     # 在 Workers 執行環境預覽
npm run deploy      # 建置並部署
npm run cf-typegen  # 產生 CloudflareEnv 型別
```

拍照辨識要在儀表板設定**執行階段**變數，不要寫進 git。Workers & Pages → `sounds-of-medicine` → Settings → Variables and Secrets：

- `OPENAI_API_KEY`：類型選 Secret。不設定就是示範模式。
- `OPENAI_MODEL`（選用，預設 `gpt-4o-mini`）
- `OPENAI_BASE_URL`（選用，預設 `https://api.openai.com/v1`）

`compatibility_date` 為 `2026-10-19` 且已開啟 `nodejs_compat`，所以上面的值在 Worker 裡可以從 `process.env` 讀到。

本機 Wrangler 預覽：`cp .dev.vars.example .dev.vars` 再填金鑰。`.dev.vars` 不會進版控。`npm run dev` 仍使用 `.env.local`。

若部署把儀表板上的變數清掉，把部署指令改成 `npx wrangler deploy --keep-vars`。

## 評審示範腳本（約五分鐘）

建議用手機寬度，或直接用電腦：寬螢幕左側有評審提詞，右側是手機畫面。

1. **語言與同意。** 選 Bahasa Indonesia（或任一語言）。同意方塊一開始是空的，沒勾就不能進。勾選「已取得被照顧者或家屬同意」後按開始。
2. **掃描。** 中間的掃描鈕打開示範藥袋。點「國泰 · 降血壓」。短暫停頓後進入讀取結果：病人、藥名、用量、數量、用法、適應症、警語、藥局、日期，中文與印尼語並列，下方有免責聲明。
3. **核對後加入藥櫃。** 打開藥卡，按「朗讀」。聽到的只有藥名、用量、用法與警語。若這支手機沒有該語言語音，畫面仍保留全文，並提示改看文字。
4. **多家醫院。** 到設定，按「一次載入四包示範藥袋」（或再逐包掃描）。藥櫃依醫院分開。脈優與安脈優會標「可能重複／請詢問藥師」。
5. **今天。** 時間軸依藥袋上的早、晚、飯後排列。點一項「已餵藥」、一項「漏吃」。可開啟瀏覽器通知並送一則測試提醒（頁面開著時最穩）。
6. **回報家屬。** 在回報頁選一項觀察（例如頭暈）送出。預覽區先顯示家屬會看到的中文。
7. **家屬頁。** 底部「家屬」整頁改為繁體中文，可看到餵藥紀錄與觀察，並用固定短句回覆。照顧者回到自己的語言會看到那句回覆的譯文。
8. **就醫摘要。** 家屬頁按「列印就醫摘要」，用瀏覽器列印或存 PDF。摘要註明內容來自藥袋與照顧者回報，不是診斷。

設定裡可以清除這支手機上的全部資料，回到語言選擇。

## 畫面

- 引導：選語言、同意（預設不勾）
- 今天：跨醫院的給藥時間軸，已餵藥／漏吃
- 掃描與讀取結果：相機、相簿，或四張示範藥袋
- 藥卡：圖示時間、劑量、警語、朗讀
- 藥櫃：多家醫院，重複成分只提示詢問藥師
- 回報與家屬：照顧者用自己的語言，家屬看繁體中文
- 列印摘要：給門診用

可安裝成 PWA（`npm run build && npm start` 後，用手機瀏覽器加到主畫面）。manifest 含 `display: standalone`、theme-color，以及一般圖示、maskable 圖示和 apple-touch-icon。版面從 320px 手機到 1440px 桌面：寬螢幕的今天、回報、家屬頁分成兩欄，其餘頁面置中。底部導覽會讓出 iPhone 的 home indicator。`npm run responsive` 會用 Playwright 在 320×740、360×740、390×844、768×1024、1024×768、1440×900 檢查每個路由有沒有橫向溢出。示範開發模式不註冊 service worker，避免快取干擾。

## 限制

- 示範藥袋是虛構患者與示意標示，不能當成真實處方。
- 瀏覽器語音依手機而定。泰語、菲律賓語可能沒有語音引擎，此時改看畫面上的字。
- 通知在網頁開著時可用。手機鎖定後的定時提醒受瀏覽器限制，這份原型不保證背景響鈴。
- 換手機或清除瀏覽器資料後，藥袋不會跟著走。
- 拍照辨識可能看錯。必須人工核對後才收入藥櫃；沒有金鑰就不會假造辨識結果。
- 藥聲不取代醫師或藥師。
